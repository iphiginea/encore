# Encore

A concert ranking app that compares shows head to head to build a personal list of the performances that mattered most.

**Live app:** https://iphiginea.github.io/encore/

## About

Encore turns concert history into a comparison system. Log the shows you have seen, then choose between two performances at a time until the ranking reflects the nights you would actually choose again.

Rather than forcing every concert onto an arbitrary rating scale, the app lets preference emerge from repeated decisions.

## Features

- Head-to-head concert comparisons
- Personal show rankings
- Artist, city, venue, and date tracking
- A growing personal concert history

## Stack

- JavaScript
- Browser-based personal data
- GitHub Pages
